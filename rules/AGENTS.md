# 文档卡片交付规范（doc-card 插件永久规则）

当你在任务中生成、修改或交付任意用户文档文件（如 `.docx`、`.doc`、`.pdf`、`.xlsx`、`.pptx` 等）时，**必须按以下三步交付**：

1. **登记到侧边栏「文档卡片助手」列表**：
   将新生成或更新的文件绝对路径写入 `~/.gemini/config/plugins/doc-card/data/files.json` 列表最前面（按路径去重，保留 `path`、`note`、`addedAt` 字段），以便用户在右侧「文档卡片助手」面板中一键使用默认软件打开、在文件资源管理器中定位或复制到桌面。

2. **在对话中内嵌带清晰底色的文档卡片（`<agent-embed>`）**：
   在当前对话的 Artifact 目录创建紧凑型 `.html` 卡片并用 `<agent-embed src="file:///..."></agent-embed>` 内嵌展示：
   - 卡片必须具有**明显区别于聊天背景的实体底色、清晰边框与柔和阴影**（浅色主题使用高不透明度纯白底色 `#FFFFFF` + `#D8E1EC` 边框，深色主题使用 `#1C1F26` 卡片底色 + `#323846` 边框），绝不能透明或与渐变背景融为一体；
   - 卡片内显示对应文件类型彩色图标（Word 蓝 / PDF 红 / Excel 绿 / PPT 橙）、加粗文件名、类型与文件大小、简短备注及完整本地路径；
   - **不要在沙盒卡片内放置任何假按钮**（避免被沙盒拦截无法点击而误导用户），仅在右侧展示轻量非交互状态标签 `✓ 已收入右侧面板`（留出 `pr-7` 右边距避开右上角系统展开图标）。

3. **紧贴卡片下方提供可点击打开右侧边栏的入口**：
   - 当 `doc-card/doc_opener` sidecar 已启用运行时，紧贴卡片下方给出可一键展开右侧操作面板的 pill 链接：`[文档卡片助手](sidecar://doc-card/doc_opener/)`，让用户点击卡片正下方的胶囊即可 100% 在右侧打开操作面板（使用「默认软件打开」与「打开资源管理器」）。
